# Роли и маршрут — уточнение 02.11.2026

Пользователь явно изменил ранее утверждённую схему. Теперь загрузка и согласование разделены.

| Роль | Код | Действия / этап |
| --- | --- | --- |
| Инженер РИРУ своего РЭС | RIRU_ENGINEER | Создание карточки, ТУ/акт ТП/АВТУ, версии, указание исправлений, отправка и пересмотр |
| Начальник РИРУ того же РЭС | RIRU_HEAD | Первый согласующий, визуальные замечания, решение, проверка собственных исправлений |
| Начальник того же РЭС | RES_HEAD | Второй согласующий после положительного решения Начальника РИРУ |
| СТП | STP | Независимая параллельная проверка |
| СУЭ | SUE | Независимая параллельная проверка |
| ТЕХБЛОК | GI | Независимая параллельная проверка; прежний технический код сохранён |

Новый цикл: RIRU_REVIEW → RES_REVIEW → CENTRAL_REVIEW / CENTRAL_COLLECTING → APPROVED либо RETURNED. Возврат с любого из двух первых этапов сразу создаёт задачу доработки инженеру; центральный возврат по-прежнему собирает остальные решения. Новая редакция снова начинает с Начальника РИРУ. Никакое отсутствие решения не считается согласованием. Самосогласование и решения одного человека в разных ролях по акту запрещены, включая предыдущие циклы. Замещение датированное; РЭС проверяется сервером/RLS.

## Миграция и история
010 вводит RIRU_ENGINEER и RIRU_REVIEW, версии маршрута актов/циклов. Прежняя RIRU_HEAD означала загрузчика: существующие назначения этой роли преобразуются в RIRU_ENGINEER с сохранением UUID назначений и замещений. Настоящего нового Начальника РИРУ нельзя выводить из автора акта; ему нужно отдельное назначение роли своей области. При отсутствии однозначного согласующего submit сообщает ASSIGNEE_CONFIGURATION, фиктивный исполнитель не создаётся.

Исторические задачи/решения/имена не переписываются. Для старого цикла workflow_version=1 код задачи RIRU_HEAD означает прежнюю доработку: app.task_role возвращает эффективный RIRU_ENGINEER для прав/очереди/badge. В исторической матрице остаются четыре прежних согласующих. Новые циклы всегда workflow_version=2 и пять согласующих. 011 запрещает менять версию маршрута существующего цикла. Незакрытые старые циклы завершаются по прежнему маршруту; следующая отправка уже использует новый. Публикации, ссылки ТУ, исходные DOCX и якоря не переписываются.

Прежние политики сроков сохраняются для истории. Для инженера скопирован прежний норматив доработки; новый норматив Начальника РИРУ — предварительно 1 рабочий день, настраивается администратором процесса и требует утверждения для эксплуатации. Начальник РЭС — 1, службы — по 2, доработка инженера — 2 рабочих дня в предварительной конфигурации.
