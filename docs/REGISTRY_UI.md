# Реестр, маршрут и история — 01.11.2026

Актуализация следующего этапа DOCX: печать карточки из действий **отключена**, кнопка «Печать DOCX» недоступна до надёжного генератора. Прежние описания печати ниже — исторические. В карточке добавлена отдельная вкладка «Документ» с явно экспериментальным просмотром/маркерами/сравнением, см. DOCX_PROTOTYPE.md. Остальные действия, матрица и фильтры сохранены.

## Открыть локально
Синтетический стенд: http://127.0.0.1:5173. Backend: http://127.0.0.1:3000/ready. Запуск после остановки: `npm run demo`; инструкция окружения — LOCAL_BROWSER_GUIDE.md. Боевой Keycloak не подключён.

Выберите «Начальник РИРУ · Адлерский РЭС». В реестре найдите `БРАУЗЕР-` для завершённого двухциклового сценария, `МАТРИЦА-` для истории/отзыва или `СРОК-` для просрочки. В каждой строке доступны карточка, матрица, решения, печать карточки, Word, история и замечания. Неактивные действия объясняют причину в tooltip. Для решений войдите Начальником соответствующего РЭС, затем СУЭ/СТП/ГИ. Цвет всегда дополнен текстом и SVG-значком.

## Реальные данные и API
- `GET /api/v1/registry`: серверные поиск, фильтры, пагинация (25 в интерфейсе, максимум 100 в API) и сводки по полной отфильтрованной доступной выборке.
- Параметры: q, resId, status, stage, from/to (включительно, Москва), comments=with/without, overdue/mine/action=true, page/limit. Поиск буквальный, `%` и `_` не wildcard; максимум 200 символов.
- Поиск: акт, договор, заявитель, адрес, структурированные technicalData последней версии (в том числе вложенные опоры/питающие центры), тексты замечаний всех циклов. Полнотекстовое извлечение Word не реализовано; отсутствующий технический реквизит не выдумывается.
- `GET /api/v1/acts/{id}/presentation` — производный текущий маршрут/статус/действия; `/timeline` — хронология. Карточка GET `/api/v1/acts/{id}` содержит оба представления в согласованной read-only repeatable-read транзакции.
- Все чтения под штатным RLS и ролью tp_runtime. Статусы не хранятся отдельными копиями. Решения вызывают прежний командный API; подсказка доступности не заменяет серверную проверку.

## Представление
РИРУ → Начальник РЭС → общая параллельная группа СУЭ/СТП/ГИ → итог. При возврате центральные задачи продолжаются; отсутствие решения не окрашивается как согласование. При пересмотре предыдущая утверждённая версия не изображается как согласование новой. Просрочка выделяется отдельно; summary показывает действующий срок задачи, а не придуманный срок документа.

Карточка содержит summary, подробный маршрут, вкладки документа/матрицы/истории. События хронологические: создание, версии, циклы, решения, замечания/исправления/проверки, возвраты, публикации, пересмотр, отзыв и закрытие сбора. Есть ссылки на версию, замечание и матрицу цикла. Автоматические события подписаны «Система». Исторические ФИО решений неизменны; миграция 006 фиксирует actor_snapshot новых событий аудита. Для старых событий без снимка используется явно маркированный LEGACY_CURRENT_PROFILE, восстановить неизвестное историческое имя нельзя.

Карточка опрашивает сервер каждые 15 секунд в видимой вкладке; матрица сохраняет свой интервал 5 секунд. Собственное решение сразу обновляет данные без F5. Выбор вкладки и исторического цикла — только UI-предпочтения, JWT в storage не сохраняется. Кнопка открытия карточки в реестре открывает документ; для матрицы используется отдельная кнопка.

## Ограничения
Печать — браузерная печать карточки, **не окончательный пакет DOCX/PDF и не печать содержимого Word**. Скачать можно сохранённый исходный DOCX. ONLYOFFICE, привязка выделенных фрагментов и генерация итогового пакета остаются следующими этапами. Сводки учитывают активные фильтры. Начальнику РИРУ устранение возвращённых замечаний доступно через карточку, а не кнопкой согласования строки.
