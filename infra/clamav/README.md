# ClamAV для TP_Approval на Amvera

Отдельный проект Amvera (тип «Приложение»), в который загружаются только `Dockerfile` и `amvera.yml` из этой папки.

- Тариф: не меньше 2 ГБ RAM — clamd держит базу сигнатур в памяти, на меньшем тарифе контейнер падает при старте.
- Публичный домен **не подключать**: сканер доступен только по внутреннему имени Amvera.
- Первый старт занимает несколько минут: freshclam скачивает сигнатуры (~300 МБ). Пока clamd не поднялся, загрузка документов в TP_Approval отвечает `SCANNER_UNAVAILABLE`.
- В проекте TP_Approval указать `CLAMAV_HOST` = внутреннее доменное имя этого проекта и при необходимости `CLAMAV_PORT` (по умолчанию 3310).
