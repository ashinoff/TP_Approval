## Что это
Согласование актов технологического присоединения Сочинского ПЭС. Деловой ключ — номер договора ТП `ххххх-хх-хххххххх-х` (без исключений). Пакет: ТУ + Акт ТП или АВТУ (+ доп. документы: ПСУ, предыдущий акт, поопорная схема).

**Маршрут** (не менять без владельца): Инженер РИРУ → Начальник РИРУ своего РЭС → Начальник РЭС → параллельно СТП, СУЭ, ТЕХБЛОК (код `GI`).

**Роли:** `RIRU_ENGINEER`, `RIRU_HEAD`, `RES_HEAD`, `STP`/`SUE`/`GI` (начальники служб — получают задачи), `STP_ENGINEER`/`SUE_ENGINEER`/`GI_ENGINEER` (только чтение всех РЭС), `PROCESS_ADMIN`, `TECH_ADMIN` (читает всё, удаляет насовсем, сервис, бэкапы; в маршруте не действует).

**Стек:** React/Vite/TS (`apps/web`), Node/Express (`apps/api`), PostgreSQL с RLS (`db/migrations`, сейчас последняя **029**), файлы на томе `/data`, ClamAV и LibreOffice Draw внутри контейнера, pdf.js 4.10.38 на сервере и в браузере (не обновлять без проверки привязок замечаний).

**Режим: тестирование.** Реальных документов и ПДн в системе нет, лишнее можно удалять. Реальные примеры владельца лежат локально и в Git не попадают.

## Развёртывание
- **Amvera, Miami:** приложение `tp-approval` (Docker, ≥ 2 ГБ RAM), БД `tp-approval-db` (CNPG). `AUTH_MODE=local`, Keycloak не используется.
- **Push в `main` → Amvera пересобирает сама** (решение владельца 04.11.2026, без PR). После пуша проверить через Amvera MCP: `getBuildLogs`, затем `getRunLogs` — успех: `TP_Approval: порт 3000, вход local` (и `Миграции применены…`, если была миграция). Не стартовало — `rebuildProject`.
- **Новая миграция** → до пуша попросить владельца временно добавить `MIGRATION_DATABASE_URL` (владелец схемы `postgres`), после запуска — удалить и перезапустить. Без новой миграции переменная не нужна. Применённые миграции не редактировать.
- Постоянно задана только `DATABASE_URL` (`tp_runtime`, без прав на схему). Разовые: `INITIAL_ADMIN_*` (пустая БД), `ADMIN_RESET_PASSWORD` (вместе с `MIGRATION_DATABASE_URL`, потом удалить обе). `CLAMAV_HOST` не задавать.
- Git на этой машине: `git -c credential.helper= -c credential.helper=manager push origin main`. `gh` не установлен.

## Перед пушем

## Решения владельца, которые легко нарушить
- Только PDF из Word/Excel, сканы отклоняются. Внешние связи бланков игнорируются, Visio-вложения допустимы, макросы/ActiveX запрещены.
- Удаление — насовсем (не корзина), только TECH_ADMIN, с вводом «УДАЛИТЬ» и записью в журнал.
- Исправления — новой версией; к печати только согласованная версия.
- Инженер до отправки только сверяет, замечания ставят согласующие.
- На печатном экземпляре нет QR и внутренней информации.
- Значения справочников не подставляются в документ — только сверка.
